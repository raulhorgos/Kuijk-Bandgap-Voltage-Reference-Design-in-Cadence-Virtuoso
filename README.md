# Kuijk Bandgap Voltage Reference Design in Cadence Virtuoso

-Designed a temperature-independent Kuijk voltage reference circuit targeting a 1.2V
output with 3% precision.

-Engineered the circuit to operate within a supply range of 1.6V to 2.0V while maintaining
a quiescent current below 30µA.

-Implemented a Miller operational amplifier with PMOS inputs to drive the reference core
and a dedicated start-up circuit to ensure reliable operation.

-Testing the implementation with multiple analysis to prove the functionality of my
design
